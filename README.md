# 观棋 (Guanqi)

**围棋 AI 引擎图形前端** · Go AI Engine Frontend

---

## 项目简介

观棋是一个为围棋 AI 引擎（KataGo）提供图形界面的 Linux 桌面程序，
核心职能是**实时呈现引擎的分析结果**：胜率、目差、候选点、局面热度。

棋由引擎计算，人通过界面**观看**引擎的思考 —— 此即「观棋」之意；
取名自中国围棋典故「观棋烂柯」。

## 界面结构

- **菜单栏（操作都在这里）**
  - **文件**：打开棋谱 / 另存为 / 研究副本（创建、切换、丢弃）
  - **对局**：新对局 / 人机对弈开关 / 难度 / 认输 / 弃着 / 让引擎认输
  - **分析**：整谱快扫…（对话框）/ 取消快扫 / 限定选点（区域开关、清除、排除列表管理、**排除首选看次优**）/
    叠加层（7 个显示开关）/ 候选显示（立即·延迟·手动）/ 目数视角（黑视角·黑白交替）/ 面板（曲线、棋谱树）
- **右侧栏（只做信息展示）**：消息、对局状态（时钟、规则、时限）、快扫进度、引擎状态与日志、
  棋谱信息、胜率与网络直觉、讲解、候选点（可点击定位 / 排除 / 沿主变前进）、失误、局后统计。

## 功能

**分析显示**

- 胜率与目差实时刷新（引擎边搜边出结果），底部曲线同时画胜率与目差，
  悬停显示该手的手数、胜率、目差、计算量与损失。
- 目数视角：**永远黑视角**或**黑白交替**（轮到谁就显示谁的胜率 / 目差），
  曲线与悬停读数同步换算；另有「网络直觉」一行，显示策略网络**未搜索**的
  胜率 / 目差直觉，与搜索结论并列对比。
- 规则跟随：自动识别棋谱 `RU[]` 规则串（中日韩英关键词宽容映射，识别不了
  会提示并按中国规则分析），也可在设置中固定为 中国 / 日本 / 韩国 / AGA /
  新西兰 / Tromp-Taylor；切换规则后历史数据自动清空重算。
  **人机对弈的规则由新对局时选定**，并写入棋谱 `RU[]`。
- 候选点：按引擎排序给出每一手的胜率、计算量与主变（PV）；棋盘上以圆圈大小
  表示计算量，并可用幽灵子预览主变、沿主变逐步前进。
- **PV 每点计算量**：可开启（分析 → 叠加层），在候选点悬停提示里显示主变每一手的
  访问次数（`L17(20) → C3(13) → …`）——**数字越小表示引擎对那一步越不确定**。
- **支路探查**：一键「排除首选看次优」（分析 → 限定选点），再点一次撤销；
  也可逐手排除（候选行「排除」按钮 / 棋盘右键）。叠加、可回退，不影响你手动排除的其它手。
- 候选点领地：聚焦某一候选点，热度图切换为「走这一手之后」的领地，
  与当前局面的领地图用不同色相区分。
- 局面热度图（领地归属）、策略热度图（网络尚未搜索时的选点直觉）、
  失误分级标注（疑问手 / 失误 / 恶手）。
- 中文讲解：逐句说明轮到谁、引擎如何评估、这一手是第几候选、比首选差多少，
  以及引擎对候选点的取舍是否确定。
- 候选类内容可设为**立即显示 / 延迟若干秒 / 手动**（按 `F`），避免浅层结果闪现误导。

**复盘**

- SGF 载入与另存：保真往返——对局信息、变着、注释、**棋谱标记与未识别属性**都原样保留
  （`AP` 保留原作者、不冒名）；另存时把局后统计与终局判定写进根注释的独立界标块，
  **不覆盖你自己的注释**，重复另存幂等。
- 棋谱树面板与变着分支导航。
- 研究副本：可从任意一手复制出独立副本，多个副本并存、随时切换。
- 限定选点：拖框限定研究区域（只看局部），或排除某些点看次优变化。
- 整谱快扫：一键把整条线（或指定手数范围）逐手算完，曲线与统计一次填满；
  可设每手计算量、只扫一方、含变着（发起前给出局面数与耗时预估）；
  扫完自动把「差异手」用更高计算量重算一遍。
- 局后统计：黑白吻合度与差异手排行（按胜率损失排序，点击跳转到该手）；
  吻合度注明数据构成（快扫 N 手 / 深度分析 M 手）。
- 小棋盘变化图：把候选点的主变在独立小盘上按可调间隔回放。
- **未保存内容保护**：棋谱有改动而未另存时，关窗 / 开新对局 / 打开其它棋谱都会先确认，
  并可选「先另存再继续」。

**人机对弈**

- 难度档位（由低到高对应引擎计算量）、让子、贴目、棋盘尺寸（9 / 13 / 19 路）、执黑或执白。
- **时限**：无限制 / 包干制 / 读秒制（制式即规则，选了就按规则判负；无限制也显示双方用时）。
  对局中不可改，规则与时限都在新对局时确定。
- **终局判定**：双方连续弃着后，按**棋谱所用规则**用引擎评估定结果并写入 `RE`
  （认输 / 超时写 `B+R`·`W+R` / `B+T`·`W+T`）；评估不够深时会自动再深算一轮再落结果。

**通用**

- 界面偏好会记住：窗口尺寸与位置、上次打开/另存的目录、各面板与叠加层开关、
  候选显示方式、目数视角、快扫设置、时限制式、规则。
- 纯自绘界面，棋盘随窗口缩放。

## 外部依赖

- **KataGo 引擎与权重**（需自备）：程序启动时在 `PATH` 中查找 `katago`，
  也可在「设置」里指定引擎路径、权重文件或权重目录、搜索线程、思考量与分析规则。
  引擎采用何种构建 / 后端（OpenCL 版 / Eigen 版）取决于用户安装的 `katago`
  二进制，并非本项目的设置项。
- **中文字体**（建议安装 `noto-fonts-cjk` 或 `adobe-source-han-sans-cn-fonts`）：
  界面按固定路径加载中文字体，缺失时中文可能显示为方框。

## 安装与运行

```bash
cargo run                 # 从源码运行（开发）
cargo build --release     # 发布构建，产物 target/release/guanqi
```

Arch 用户可参考 `packaging/arch/PKGBUILD` 自行打包安装。

## Headless 验证工具

`examples/headless.rs` 是不开窗口的交互验证工具：用 `egui::Context`
逐帧驱动 `logic()` 与 `ui()`，输入全部走 `egui::RawInput`（不用外部注入
工具），引擎仍是**真实 katago 子进程**。用于验证状态机、时序与控件
行为，并输出结构化状态快照供断言。

```bash
cargo run --release --example headless              # 跑内置自证脚本
cargo run --release --example headless -- 脚本.txt   # 跑自己的脚本
cargo run --release --example headless -- -          # 从 stdin 读脚本
```

脚本动作：`wait` / `click` / `click_label` / `rclick` / `drag` / `wheel`
/ `key` / `keys` / `load` / `save` / `dump` / `probe` / `viewport` /
`quit`。完整语法、坐标标定方法与边界说明见文件头注释。

要点：

- **优先用 `click_label` 而非坐标**。侧栏是滚动容器，且内容高度随
  异步引擎结果浮动，同一控件的 y 坐标在两次运行间能差几百 points，
  硬编码坐标只在单次运行内有效。
- **滚动与点击前要让滚动停稳**。egui 的滚轮带平滑衰减，控件矩形反映
  的是上一帧，滚动未停时取到的坐标必然滞后（表现为点击打空）。
- 帧间真 sleep（默认 30ms），批量推进 / 心跳 / 时限按真实墙钟计算，
  不伪造时序。
- 配置隔离：运行期把 `XDG_CONFIG_HOME` 指向 `/tmp` 下的独占目录，
  **不碰真实的 `~/.config/guanqi/`**。
- **不做视觉验证**：不覆盖渲染、字体与合成器差异，视觉观感需人工看。
