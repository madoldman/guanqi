# 观棋 (Guanqi)

**围棋 AI 引擎图形前端** · Go AI Engine Frontend

---

## 项目简介

观棋是一个为围棋 AI 引擎（KataGo）提供图形界面的 Linux 桌面程序，
核心职能是**实时呈现引擎的分析结果**：胜率、目差、候选点、局面热度。

棋由引擎计算，人通过界面**观看**引擎的思考 —— 此即「观棋」之意；
取名自中国围棋典故「观棋烂柯」。

## 功能

**分析显示**

- 胜率与目差实时刷新（引擎边搜边出结果），底部曲线同时画胜率与目差，
  悬停显示该手的手数、胜率、目差、计算量与损失。
- 候选点：按引擎排序给出每一手的胜率、计算量与主变（PV）；棋盘上以圆圈大小
  表示计算量，并可用幽灵子预览主变、沿主变逐步前进。
- 候选点领地：聚焦某一候选点，热度图切换为「走这一手之后」的领地，
  与当前局面的领地图用不同色相区分。
- 局面热度图（领地归属）、策略热度图（网络尚未搜索时的选点直觉）、
  失误分级标注（疑问手 / 失误 / 恶手）。
- 中文讲解：逐句说明轮到谁、引擎如何评估、这一手是第几候选、比首选差多少，
  以及引擎对候选点的取舍是否确定。
- 候选类内容可设为**立即显示 / 延迟若干秒 / 手动**（按 `F`），避免浅层结果闪现误导。

**复盘**

- SGF 载入与另存：保留对局信息、变着与注释；另存时会把局后统计写回根注释
  （独立界标块，不覆盖你自己的注释）。
- 棋谱树面板与变着分支导航。
- 研究副本：可从任意一手复制出独立副本，多个副本并存、随时切换。
- 限定选点：拖框限定研究区域（只看局部），或排除某些点看次优变化。
- 整谱快扫：一键把整条线（或指定手数范围）逐手算完，曲线与统计一次填满；
  可设每手计算量、只扫一方、含变着（发起前给出局面数与耗时预估）；
  扫完自动把「差异手」用更高计算量重算一遍。
- 局后统计：黑白吻合度与差异手排行（按胜率损失排序，点击跳转到该手）。
- 小棋盘变化图：把候选点的主变在独立小盘上按可调间隔回放。

**人机对弈**

- 难度档位（由低到高对应引擎计算量）、让子、贴目、棋盘尺寸（9 / 13 / 19 路）、执黑或执白。

**界面**

- 纯自绘界面，棋盘随窗口缩放；曲线、棋谱树、小棋盘面板按需开关。

## 外部依赖

- **KataGo 引擎与权重**（需自备）：程序启动时在 `PATH` 中查找 `katago`，
  也可在「设置」里指定引擎路径、权重文件或权重目录、后端与思考量。
- **中文字体**（建议安装 `noto-fonts-cjk` 或 `adobe-source-han-sans-cn-fonts`）：
  界面按固定路径加载中文字体，缺失时中文可能显示为方框。

## 安装与运行

```bash
cargo run                 # 从源码运行（开发）
cargo build --release     # 发布构建，产物 target/release/guanqi
```

Arch 用户可参考 `packaging/arch/PKGBUILD` 自行打包安装。

## 快捷键

| 操作 | 按键 |
|---|---|
| 落子 | 点击交叉点 |
| 前进 / 后退一手 | `→` / `←` |
| 切换变着分支 | `Ctrl+→` / `Ctrl+←` |
| 悔棋 | `Ctrl+Z` |
| 打开棋谱 | `Ctrl+O` |
| 另存为 | `Ctrl+Shift+S` |
| 显示候选点（仅「手动」门控模式） | `F` |
